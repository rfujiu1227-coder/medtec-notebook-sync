Privacy Policy

Last updated: 23 November 2026

Who uses this app

MEDTEC Notebook Sync is a personal tool. Its only user is its developer, who authorises it with his own Google account.

What data the app accesses

With the owner's permission, the app uses the Gemini Notebook API to list the owner's notebooks and to add lecture transcript files from the owner's Google Drive to those notebooks.

How the data is used

The data is used only to add the owner's own files to the owner's own notebooks. The app does not read notebook contents for any other purpose.

Storage and sharing

The app runs entirely on the owner's computer. It does not send data to any server other than Google's own APIs, does not sell or share data with anyone, and does not use data for advertising or for training AI models. The only information kept locally is a list of files already added, so that the same file is not added twice.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.
